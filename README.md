AIM : To study for loop in python

THEORY - This program demonstrates the use of the for loop in Python to perform repetitive tasks such as printing sequences,
calculating sums, working with matrices, generating patterns, and identifying prime numbers.
A for loop iterates over a sequence generated by the range() function.

ALGORITHM :

(1). Print Numbers from 1 to 5

- Start
 
- Initialize loop variable from 1 to 5

- Print the current number

- Repeat until the loop ends
  
- Stop

(2). Print Odd Numbers from 1 to 10

- Start

- Initialize loop from 1 to 10 with step size 2

- Print each value (odd numbers only)

- Continue until the loop finishes

- Stop

(3). Sum of First N Natural Numbers

- Start

- Input value of N

- Set sum = 0

- For each number from 1 to N
  
     ~ Add the number to sum
  
- Display the final sum

- Stop

(4). Display a 3×3 Matrix (Nested Loop)

- Start

- Define a 3×3 matrix

- For each row in the matrix

- For each column in that row

- Print the element

- Move to the next line after each row

- Stop

(5). Multiplication of Two 3×3 Matrices

- Start

- Define Matrix A and Matrix B

- Create result matrix C initialized to zero

- For each row i in Matrix A

   ~ For each column j in Matrix B

   ~ Set C[i][j] = 0

   ~ For each element k

   ~ Multiply A[i][k] × B[k][j]

   ~ Add to C[i][j]

- Display result matrix C

- Stop

(6). Display Matrix Using Direct Iteration

- Start

- Define matrix A

- For each row in matrix A
 
    ~ Print the row
  
- Stop

- Start

- Initialize loop from maximum rows down to 1

(9). Pyramid Star Pattern

- Start

- Input number of rows

- For each row from 1 to N

     ~ Print spaces (N − row)

     ~ Print stars equal to row number

- Move to next line

- Stop

(10). Inverted Pyramid Pattern

- Start

- Input number of rows

- For each row from 0 to N−1

    ~ Print leading spaces
